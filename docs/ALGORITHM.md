# 算法与误差保证

给定有限且递增的区间 `[a,b]` 与回调值，初始非零值必须异号。连续函数的介值性质说明区间中至少有一个根；浮点程序额外依赖回调符号可靠，无法验证数学连续性。

## 二分

候选是中点。异号端点用 `a/2+b/2` 避免 `b-a` 溢出；其余情况用 `a+(b-a)/2` 避免 `a+b` 溢出。若舍入后的中点等于端点，容差未满足时返回 `FloatingPointLimit`。

## 保护割线

理论权重 `w=abs(f(a))/(abs(f(a))+abs(f(b)))`。实现先把较小绝对值除以较大绝对值，再构造权重，不直接计算可能溢出的分母。区间差有限时使用 `a+(b-a)*w`，否则使用凸组合。

候选必须严格位于中央半区间。拒绝非有限值、贴近端点的点和中央半区间外的插值；退回二分。更新时仅用 `<0` / `>0` 比较保持端点异号，避免乘积下溢为零或上溢为无穷。

每次更新只替换一个同号端点，区间嵌套。实数模型中每步新区间宽度至多为旧宽度的 3/4；回归检查为浮点舍入留有余量。算法可因函数形状比二分更慢，不作速度或超线性收敛承诺。

## 终止顺序

1. 参数合法性检查发生在任何回调前。
2. 求值两个端点并确认有限；遇浮点零立即结束，否则检查异号。
3. 先判断区间容差，再判断迭代预算。
4. 无可表示的内部中点时报告精度限制。
5. 求值候选；非有限值返回错误，浮点零成功，其余更新区间并重复。

`max_iterations=0` 仍可接受端点零或已经足够窄的初始区间，但不会求值内部点。预算用尽是可检查的非收敛结果。

## 为什么用全宽

返回点选择已评估且绝对函数值较小的端点，其到区间内任意根的距离上界为整个区间宽。以 `(x-0.875)*(1+63*x)^2`、区间 `[0,1]` 为例，残差较小的端点是 0，离根却有 0.875；半宽 0.5 无法认证该端点的误差。

`narrow_enough` 要求区间差有限，然后与 `atol+rtol*abs(root)` 比较，防止 `Infinity <= Infinity` 误报。库不检查绝对函数值阈值，因为函数单位/尺度改变会让这种阈值产生错误结论。

若两个端点相邻（如 1 与其上一个相邻双精度数），数学中点不可表示；默认不把停滞当作收敛。若要求的绝对容差小于机器可达精度，调用者应检查终止原因而非无限增加迭代数。

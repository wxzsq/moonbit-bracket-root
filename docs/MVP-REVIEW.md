## 实际交付范围

核心是 MoonBit 原生的二分法和保护割线法，输入为函数、区间、位置容差与预算，
输出为根估计、残差、最终区间和终止诊断。它提供区间轨迹、可关闭轨迹的批量模式、
JSON/CSV 导出，以及有明确局限的候选区间扫描。CLI 与交互页调用同一份编译后的 MoonBit 代码。

| 场景 | 输入与运行命令 | 可核对的输出 |
|---|---|---|
| 算法教学 | `node tools/run-demo.mjs sqrt 2 bisect` | 根约 1.414213562373，轨迹逐步缩小 |
| 标定反解 | `node tools/run-demo.mjs calibration 2.375 bisect` | 归一化输入 2.5，对应响应 2.375 |
| 冷却阈值 | `node tools/run-demo.mjs cooling 50 secant` | 约 6.9314718056 分钟达到模拟温度 50 °C |
| 预算不足 | `node tools/run-demo.mjs sqrt 2 bisect 0` | `converged=false`、`iteration_limit`，退出码 3 |
| 不可达目标 | `node tools/run-demo.mjs cooling 20 bisect` | 输入/模型错误，退出码 2 |

标定与冷却均为模拟模型，具体公式、单位与适用范围见相应文档。
命令需要已安装 Node.js 18+ 和 MoonBit；工具链版本及配置见 [复现说明](REPRODUCING.md)。

## 一次运行全部自动检查

```sh
node tools/verify.mjs
```

当前验证为 33 项 MoonBit 测试、16 组 JavaScript/CLI 检查及三个示例全部通过。
另有3项独立消费模块测试及其自定义三次方程可执行程序，包含在同一验证入口中。
其中 MoonBit 原有一个测试块包含两种算法合计 1000 个确定性缩放问题；不把这些内部
用例重复算作 1000 项测试。脚本保留工具版本、日志与成功标记，每轮使用新构建目录。

运行 `node tools/serve-demo.mjs` 后打开 `http://127.0.0.1:4317` 可手动检查：
选择三个场景、切换算法、更改目标、设置零次预算、导出轨迹。页面检查已覆盖三个
正常场景、预算不足、不可达目标，以及修改输入后清除旧结果。文件下载内容已通过
JSON/CSV 集成检查核对；未把浏览器下载操作本身列为自动化测试。
